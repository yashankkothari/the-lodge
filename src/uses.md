# Uses

The tools on the workbench. Nothing here is sponsored; most of it was chosen at 2 a.m.

## Desk

- **Machine:** AMD Ryzen 5 5600X, 32 GB DDR4, Gigabyte Radeon RX 9060 XT 16 GB
- **Monitors:** BenQ EW270Q and Gigabyte G24F, side by side
- **Keyboard:** Cosmic Byte mechanical, in white
- **Mouse:** Razer Orochi V2
- **Also on the desk:** iPad Air 2
- **Headphones:** Razer BlackShark V2 X. For Badalamenti, mostly.
- **Speakers:** Creative Pebble V3
- **Mic:** Blue Snowball iCE

## Editor & terminal

- **Editors:** Neovim and VS Code
- **Terminal:** kitty
- **Version control:** Git, GitHub

## Data work

- **Databases:** Oracle (PL/SQL), PostgreSQL, Snowflake, AWS RDS
- **Pipelines:** Apache Airflow, dbt with Jinja-templated SQL
- **BI:** Domo, Sigma Analytics, Grafana
- **Analysis:** Python, pandas, NumPy, Matplotlib

## Building things

- **Web:** React, Next.js, Node.js, FastAPI
- **Mobile:** React Native with Expo
- **Containers:** Docker
- **This site:** Eleventy, Nunjucks and hand-written CSS. No framework, no tracking.
