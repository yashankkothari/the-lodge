# Technology logo sources

The full-color SVG marks are the original brand assets distributed by the [Devicon project](https://github.com/devicons/devicon/tree/master/icons). Files retain their original colors and proportions. Snowflake's mark is the locally stored Simple Icons asset documented in `../uses/sources.md`. SQL, PL/SQL, dbt, and AWS retain their existing vector glyphs with semantic color tokens.

Each local file uses `https://raw.githubusercontent.com/devicons/devicon/master/icons/<name>/<name>-original.svg`, with `<name>` matching its filename. Retrieved 18 November 2026.
