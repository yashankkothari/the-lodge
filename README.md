# the-lodge 🪵

my little corner of the internet: **[yashank.site](https://www.yashank.site)**

a hand-built personal site and blog where i write about data, ai agents and llms, show off projects, and keep a /now page of what i'm up to.

## what's inside

- 📝 **blog** with tags and an rss feed
- 🧪 **projects** and portfolio pages
- 🕰️ **/now** and **/uses** pages
- 💻 a terminal-style easter egg, a stats page, and a minimal mode
- 📄 résumé page

## built with

[![Stack](https://skillicons.dev/icons?i=html,css,js,vercel)](https://skillicons.dev)

[eleventy](https://www.11ty.dev) · nunjucks · markdown · deployed on vercel

## run it locally

```bash
git clone https://github.com/yashankkothari/the-lodge.git
cd the-lodge
npm install
npm start   # eleventy --serve
```

build for production with `npm run build`.
